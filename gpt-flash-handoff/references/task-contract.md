# 任务契约模板（派发 Flash 执行子代理用）

本文件是 SKILL.md 第 2 节的配套模板。契约要在**派发之前**写完，并且**自包含**：执行子代理看不到主模型会话的上下文，凡是它需要的都必须在契约里。

---

## 一、空白模板（复制后逐项填写）

```
【任务名】<3-5 词，用于展示>

【目标】
<要达成什么。用可判定的完成态描述，而不是"尽力优化"这类模糊说法。>

【输入与必要上下文】
- <文件/数据的相对路径或明确标识，以及它是什么>
- <已知的结论、接口约定、前一步产物>
- <只给必要信息；不要把无关凭据、密钥或整份私密配置复制进来>

【可修改 / 禁止修改的范围】
- 允许创建或修改：<确切目录或文件清单>
- 禁止触碰：<目录/文件/系统区域。/ 不越权做数据库写入、部署、破坏性操作>
- 并行约束：<若并行派发，写清"本子任务的可写范围与其它子任务不重叠">

【约束】
- 环境与权限：<可用工具、不可用的做法、是否需要审批>
- 接口/风格：<命名、格式、语言、依赖限制>
- 执行方式：<不得递归委派；发现被路由到与契约不符的模型时停下回报，不得静默换模型>

【交付物】
- <产物 1 的确切路径> —— <形态：文件/补丁/报告，关键内容要求>
- <产物 2 的确切路径> —— <形态>

【验收标准】（必须在派发前写明：检查方法 + 预期结果）
| # | 检查项 | 检查方法（命令/动作） | 预期结果 |
| --- | --- | --- | --- |
| 1 | <如：产物存在> | <如：读取该路径 / 列目录> | <如：文件存在且非空> |
| 2 | <如：行为正确> | <如：运行 <测试命令>> | <如：全部用例通过，退出码 0> |
| 3 | <如：边界> | <如：构造 <边界输入> 后运行> | <如：返回明确错误而非崩溃> |

【回报要求】
产物路径、改动摘要、**实际执行过的**验证及其原始结果、未完成项、风险。
子代理不得自行宣布用户任务最终验收通过。
```

## 二、检验例 A：代码任务

**填写示例（结构示范，非真实项目）**

```
【任务名】修复解析器空输入崩溃

【目标】解析器收到空字符串时不再抛异常，而是返回空结果集，且现有行为不变。

【输入与必要上下文】
- src/parser.py —— 目标模块
- tests/test_parser.py —— 现有测试
- 已知：空输入当前抛 IndexError；调用方在 src/app.py 依赖非空返回值。

【可修改 / 禁止修改的范围】
- 允许修改：src/parser.py
- 禁止修改：tests/ 下任何已存在的用例、src/app.py
- 不得新增第三方依赖

【约束】
- 保持公开函数签名 parse(text: str) -> list[str] 不变（这是本示例的签名：示例规则下条目都是字符串，故元素类型为 str；原示例写作 parse(text: str) -> list[Item]，其中 Item 未定义，为与下方 parse("难") → ["难"] 的单点预期一致而统一为 list[str]；模板/真实项目请替换成自己的真实签名）
- 不递归委派；若被路由到与契约不符的模型，停下回报

【交付物】
- src/parser.py —— 改动后的模块
- 变更说明：改动点、理由、影响面

【验收标准】
（示范用解析器规则——真实项目替换成自己的规则，但必须写死一条明确规则，否则边界预期不可判定：
 条目按行分隔；每行 strip() 后为空则忽略；单个字符是一个合法条目；输入长度上限 L = 10000，超过上限抛 ValueError。
 示范测试命令：`python -m pytest tests/test_parser.py -q`；单点调用也可用
 `python -c "from src.parser import parse; print(repr(parse('   ')))"`。）
| # | 检查项 | 检查方法（命令/动作） | 预期结果 |
| --- | --- | --- | --- |
| 1 | 回归 | 运行 `python -m pytest tests/test_parser.py -q` | 原有全部用例通过，退出码 0 |
| 2 | 目标行为 | 调用 parse("") | 返回 []，不抛异常 |
| 3a | 边界·空白 | 调用 parse("   \n\t ") | 返回 []（按上述规则空白行被忽略） |
| 3b | 边界·单字符 | 调用 parse("难") | 返回 ["难"]（单字符按上述规则是合法条目） |
| 3c | 边界·超长 | 调用 parse("a" * 10001)（超过 L = 10000） | 抛 ValueError 且消息含长度上限；不崩溃、不静默截断 |
| 4 | 范围 | 查看 diff | 仅 src/parser.py 被改 |
```

**代码任务验收时 GPT 自己要做的（对应 SKILL.md 第 5 节）**

| 检查项 | 检查方法 | 预期结果 |
| --- | --- | --- |
| 真的改了 | `read` 改动文件与 diff | 差异与契约一致，无夹带改动 |
| 真的能跑 | 复跑测试/构建 | 通过；失败则记录原始输出 |
| 契约边界 | 检查是否只碰允许范围 | 越界改动 = 验收不通过 |
| 未测项 | 逐条核对验收表 | 每条都有实际结果，缺失的明确标注"未验证" |

## 三、检验例 B：分析/研究任务

**结构要点**：分析类契约的核心是**可追溯**——每个关键结论都要能回到来源，每个关键数值都要能复核。

```
【任务名】统计 X 在样本中的出现频次

【目标】输出一张频次表，并对每个数值给出可复核的来源定位。

【输入】<数据集标识 / 目录 / 查询口径；说明统计粒度与时间范围>

【范围】只读；允许写入的产物只有 <报告路径>

【约束】不得推测：无法从输入得出的结论必须标注"数据未覆盖"；不递归委派；若被路由到与契约不符的模型，停下回报

【交付物】<报告路径> —— 含：方法、频次表、每条数值的来源定位、局限

【验收标准】
| # | 检查项 | 检查方法 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 来源可追溯 | 抽 3 条结论回到原始来源核对 | 每条都能定位且一致 |
| 2 | 数值可复核 | 用独立方式重算抽样若干项 | 与报告数值一致 |
| 3 | 口径明确 | 检查是否写清统计口径与时间范围 | 有明确声明，无含糊表述 |
| 4 | 局限 | 检查是否标注未覆盖的部分 | 缺失处被显式标注，而非静默省略 |
```

**分析任务验收时 GPT 自己要做的**

| 检查项 | 检查方法 | 预期结果 |
| --- | --- | --- |
| 关键数值 | 自己重算抽样项 | 与子代理报告一致；不一致 = 验收不通过 |
| 来源 | 自己打开来源核对引用 | 引用真实存在且支持结论 |
| 逻辑 | 检查结论是否由数据支撑 | 无"跳步"结论；推测被标注为推测 |
| 未执行 | 检查未完成验证项是否列明 | 无隐藏的未验证结论 |

## 四、检验例 C：文档/产物任务

**结构要点**：文档类契约的核心是**覆盖 + 格式 + 事实**三件事，且事实要能被独立核对。

```
【任务名】编写 <主题> 说明文档

【目标】产出一份覆盖 <必含章节清单> 的文档

【输入】<素材来源；指定哪些是权威来源>

【范围】允许创建/修改：<文档路径>；不改动来源素材

【约束】格式：<语言、标题层级、章节顺序、术语表>
        不得编造事实；无法确认的写"待确认"，并集中列在末节
        不递归委派；若被路由到与契约不符的模型，停下回报

【交付物】<文档路径>

【验收标准】
| # | 检查项 | 检查方法 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 存在与编码 | 读取该文件 | 存在，UTF-8 可正常解码，无乱码 |
| 2 | 内容覆盖 | 对照必含章节清单逐项查 | 每章都在，无缺失 |
| 3 | 格式 | 检查标题层级/顺序/术语 | 与约定一致，无跳级标题 |
| 4 | 事实 | 抽 <N> 处事实陈述回到来源核对 | 与来源一致；不确定的都在"待确认"节 |
| 5 | 篇幅/边界 | 对照范围要求 | 无超范围内容，无越界改动来源文件 |
```

**文档任务验收时 GPT 自己要做的**

| 检查项 | 检查方法 | 预期结果 |
| --- | --- | --- |
| 打开确认 | 自己 `read` 成品 | 可读、结构完整 |
| 事实抽查 | 自己核对若干处事实 | 与权威来源一致 |
| 待确认项 | 检查"待确认"节 | 悬空事实被显式列出，而不是被粉饰为确定结论 |
| 改动范围 | 检查来源素材 | 未被改动 |

## 五、校验清单（GPT 写完契约后自查）

| # | 检查项 | 预期结果 |
| --- | --- | --- |
| 1 | 六要素齐备 | 目标/输入/范围/约束/交付物/验收标准 都在 |
| 2 | 自包含 | 执行子代理无需主模型会话上下文即可开工 |
| 3 | 验收标准可验证 | 每条都有检查方法与预期结果，不是"做得好" |
| 4 | 范围明确且不重叠 | 允许写的位置写死；并行子任务可写范围互不重叠 |
| 5 | 信息最小化 | 逐条检查契约里出现的个人信息、路径与凭据：**只含完成任务必需且已获授权**的信息（例如为定位目标文件所必需的文件名、为检索所必需的姓名字段），且出现的每条个人信息都能对应一项任务必要用途；**不含与该任务无关**的凭据、密钥、个人记忆、账号/IP/主机绝对路径、本机专属路由，无关凭据/秘密为零（模板与真实契约的区分见下方「注意区分两个层次」） |
| 6 | 边界写明 | 不递归委派、不越权、不静默换模型 |
| 7 | 路由已确认 | 已用 `list_subagent_models` 现场确认 provider/model，并显式传入 |

**注意区分两个层次，别把分享要求误加到实际任务上**：

- **本文件（可分享模板）**：只放占位符，自身不得固化任何具体机器的路径、账号、IP 或专属路由。
- **实际任务契约**：允许包含**完成该任务所必需且已获授权**的具体信息——包括定位目标文件所需的路径、姓名/关键词检索所需的姓名等。判断标准是「是否为本任务必要且获授权」，而不是「是否提到个人信息」。无关的凭据、密钥、个人记忆才必须剔除。
